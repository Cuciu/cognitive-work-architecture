# Knowledge Files

This folder expects `.md` files at runtime containing domain-specific 
knowledge for the RAG pipeline.

## Expected Files
- advisory.md
- cloud.md
- cwa.md
- enterpriseai.md
- finops.md
- global.md
- presales.md
- sovereign.md

## Format
Each file should contain structured markdown covering:
- Service description
- Key capabilities
- Differentiators
- Relevant metrics / case studies

See the project README for details on content structure.
